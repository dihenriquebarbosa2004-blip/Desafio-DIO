# Desafio Excel

## Sobre o projeto

Este projeto foi desenvolvido como parte do desafio do curso de Excel, com o objetivo de aplicar na prática os conhecimentos apresentados nas vídeo-aulas.

## Conteúdos abordados

Durante o desenvolvimento do projeto, foram utilizados conhecimentos relacionados a:

* Fórmulas de busca;
* PROCV;
* Fórmulas de tratamento de texto;
* DIREITA;
* EXT.TEXTO;
* PROCURAR;
* SUBSTITUIR;
* Organização e tratamento de dados;
* Análise de informações no Excel.

## Arquivo do projeto

O arquivo principal deste repositório é:

* `Desafio.xlsx` — planilha desenvolvida para a realização do desafio.

## Objetivo

O objetivo foi colocar em prática os conhecimentos adquiridos durante as aulas e desenvolver uma planilha utilizando os recursos e fórmulas apresentados no curso.
